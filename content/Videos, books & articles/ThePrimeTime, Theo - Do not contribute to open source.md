- Don't be obligated to contribute to open source, as this thinking is responsible for meaningless contributions.  
- Think about contributing after you are already using the project, love it, and have read the documentation to be sure you are not just using the program the wrong way.  
- Don't make a pull request immediately, but rather write a concise Issue, in which you write the description of the problem, reproduction steps, and problematic code and how you would go about fixing it.  
- At the end of the day, 0 contribution requests is better than any number of bad contribution requests.
